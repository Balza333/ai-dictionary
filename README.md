# AI技術辞典

初心者向けに、38個のAI用語の説明と使用例を収録したWebアプリです。

## 使う

- [AI技術辞典を開く](https://balza333.github.io/ai-dictionary/)
- [音声学習を開く](https://balza333.github.io/ai-dictionary/audio.html)
- [関連用語マップを開く](https://balza333.github.io/ai-dictionary/map.html)

スマートフォンでは上のリンクをブラウザで開いてください。
パソコンでは、このリポジトリのファイルをまとめて保存し、index.htmlを開く方法でも使えます。

## 機能

- 用語・説明・使用例の検索、カテゴリ絞り込み
- お気に入り、学習済みの記録（同じブラウザ内のlocalStorageに保存）
- ランダムな10問の4択クイズと答え合わせ
- 全体／周辺の関連用語マップ（38語・41本の関係線）
- 聞き流しと音声クイズ。カテゴリ・語数・順番・速度・待ち時間を設定可能

## 音声学習の注意

対応ブラウザと端末内の読み上げ音声が必要です。日本語音声を優先し、外部の読み上げサービスは使用しません。
画面消灯や他アプリへの切り替え中の連続再生は保証できません。この実装では画面が隠れたら一時停止し、戻って「再開」を押す方式です。
再開は中断した文の先頭から、音声クイズの待ち時間は残り時間からです。
詳しくは[音声学習の制約](音声学習の制約.md)を参照してください。

## 構成と公開

HTML・CSS・JavaScriptだけで構成されています。外部API、サーバー処理、ビルド、追加ライブラリは不要です。
GitHub Pagesはmainブランチのルートにあるindex.htmlを入口にします。
.nojekyllは、これらの静的ファイルをJekyllで変換せずに配信するためのファイルです。

ブラウザの記録は別の端末・ブラウザとは同期されません。ローカルファイルで使っていた記録も公開サイトへ自動では移りません。
